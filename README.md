# Keeply

**Know what you bought, where the receipt is, and how long you have to return it.**

Keeply is a local-first desktop app that keeps your receipts, tracks return windows
and warranty expiry, and lets you find any purchase in seconds.

No account. No cloud. No subscription. Your receipts never leave your computer.

> This repository is under active development toward v1.0.0.

## Status
